📊Sales Performance Dashboard

📘 Overview
This project provides a clear analysis of sales performance as part of Internship Task 1.
It combines Python (for data analysis) and Power BI (for dashboards) to highlight key business insights.

🎯 Key Insights
 Revenue: ₹1.12bn generated from 15K orders.

 Top Categories: Beauty & Electronics drive the highest sales.

 Payments: Digital methods (Credit Card + UPI) dominate.

 Regions: Rajasthan & Sikkim lead in revenue.

 Challenges: ~33% of orders are pending or returned — improvement needed.

📂 Deliverables
 Notebook: Data cleaning & analysis (sales_analysis.ipynb)

 Report: Business Insights (Business_Insights_Report.pdf)

 Dashboard: Combined PDF (Dashboard_Report.pdf)

 Source File: Power BI (Sales_Performance.pbix)

✅ Purpose
 This dashboard helps decision‑makers quickly understand performance trends, customer behavior, and   areas for improvement.
